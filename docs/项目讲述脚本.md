# 项目讲述脚本 —— 1 分钟 / 3 分钟两档 + 追问接招

> 面试的自我介绍和项目环节，**先定档再开口**：面试官说"简单介绍一下"用 1 分钟版；说"详细讲讲这个项目"用 3 分钟版。讲完停下，把话语权交回面试官——**追问才是你的主场**（标准答案见[面试问答手册](面试问答手册.md)）。

---

## 一、1 分钟版（电话面 / 开场自我介绍后的项目段）

> 我做了一个电商经营诊断的分析项目，用的是 UCI 公开的英国在线零售商数据，54 万行真实订单。整个链路是：数据清洗——先做缺失、重复、异常、口径四查，把 54 万行整理成 39 万行干净数据；然后围绕 7 个业务问题分析——经营趋势、RFM 客户分层、同期群留存、商品集中度、市场结构、下单时段、退货诊断；最后输出 11 张图表和五条可落地建议。技术上用 pandas 做分析、SQL 做了同一套问题的对照实现并用自动化脚本验证了一致性。项目里我自己最满意的一个发现是：退货流水里 57% 其实是亚马逊平台费冲销，把退货率从 7.8% 修正到真实的 3.5%，避免了业务方跑偏的治理动作。

**要点**：数据规模 → 三段链路 → 7 问题 → 技术栈 → 一个记忆点。不要展开细节。

## 二、3 分钟版（项目详述环节，按 STAR 展开）

**S · 背景（30 秒）**
> 我把自己放在"这家英国礼品电商数据分析师"的位置上。这是一家 B2B 为主的批发生意，卖手工风节日礼品。老板的核心疑问是三件事：生意好不好、客户怎么样、哪里在漏水。我的任务就是用数据回答，并给出能落地的动作。

**T · 数据与清洗（45 秒）**
> 数据是 UCI 的真实交易流水，54 万行、13 个月。我没有直接动手，先做了"体检四查"：缺失、重复、异常、口径。体检发现了四个必须处理的点：25% 的行缺客户 ID、5 千多行完全重复、退货和取消单混在销售里、最后一天只采集到中午。清洗的原则是每一刀都有业务理由——比如末日不删，12 月会"暴跌 71%"误导业务；客户 ID 缺失不填充，因为标识列填了会把一群客户伪装成一个。最后 54 万行变成 39 万行销售明细加 1 万行退货明细，全程有清洗日志。

**A · 分析（75 秒）**
> 分析不是画图，是回答问题。我列了 7 个业务问题逐一回答，讲三个有代表性的：
> 第一，**客户价值**：RFM 按四分位打分做 8 分层，发现重要价值客户以 30% 的人数贡献 74% 的 GMV，强二八分化，每一层我都映射了对应的运营动作；
> 第二，**留存**：用同期群分析按首购月分组追踪，平均次月留存只有 20.4%，而且各月形态相似——说明不是某个月出了事故，而是首购后的承接动作一直缺失，这就是最大的漏水口；
> 第三，**退货**：流水口径退货率 7.84%，但下钻发现 57% 是亚马逊平台费和手工调整的冲销，真实商品退货率只有 3.5%，而且集中在陶瓷储物罐这类易碎品上，1 月还有一个圣诞退货潮的冲高。不拆口径，退货治理就会全面收紧政策、误伤批发客户。

**R · 结论与产出（30 秒）**
> 最终交付 11 张图和五条建议，每条都是"数据发现→业务归因→落地动作→预期指标"的四段式，比如把次月留存从 20% 提到 30% 的自动化触达方案。工程上三个 notebook 职责分离，SQL 版本用 SQLite 做了自动一致性验证，整个项目可以一键复现。

## 三、追问接招（讲完必被追问，提前备好)

| 追问 | 接法（先给结论，再给数字） |
| --- | --- |
| "留存 20% 怎么个差法？" | 内部对照：2010-12 圣诞群 36% vs 后续 15~23%；承认缺行业基准，可 A/B 验证 |
| "为什么用 RFM 不用聚类？" | 可解释+可执行映射运营动作；4,333 样本聚类不稳；是方法论决策 |
| "25% 缺失删掉不心疼？" | 标识列不可填充；删前量化金额、留痕披露；建议业务补录 |
| "建议怎么落地？" | 四段式链条 + A/B 先行小流量验证 |
| "最大的坑是什么？" | 退货口径：57% 是财务冲销；教训是敢怀疑算出来的数字 |
| "SQL 也能做吗？" | 能，sql/ 目录整套实现，NTILE 打分、窗口函数帕累托；SQLite 自动验证 PASS |
| "数据量翻 100 倍呢？" | 分块/降 dtype → SQL 下推聚合 → Spark/Hive；分析逻辑与引擎解耦 |

## 四、讲述时避免的三个坑

1. **不要从"我下载了数据"开始讲**——从业务问题开始，数据是手段；
2. **不要报流水账**（"然后我又画了一个图……"）——每个环节以"发现"收尾；
3. **不要抢答**——讲到"11 张图和五条建议"就停，把追问的空间留给面试官。
